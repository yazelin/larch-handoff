孕吐時床頭放蘇打餅乾

  • 結論：衛教資料建議孕吐時少量多餐、選乾燥鹹味的食物如餅乾；多家美國醫院衛教把「床頭放蘇打餅乾、下床前先吃幾片」歸給美國婦產科醫學會（ACOG），但沒找到 ACOG 原頁面。空腹容易引發噁心。效果因人而異。

先生能不能進產房陪產

  • 結論：早年因感染控制，先生只能在產房外等，後來推行以家庭為中心的照護才逐漸開放。自然產多數醫院開放一位家屬陪產、剖腹產通常不開放手術房，這一點沒找到全台統一規定，各醫院自訂。

憂鬱症住院多久

  • 結論：沒找到台灣憂鬱症專屬的全國平均住院天數。林口長庚早年研究精神科住院平均約 35 天；健保資料老年精神科住院平均約 44 天。急性住院大約幾週到一兩個月，之後是日間留院、門診追蹤，完全恢復可能要好幾年。
